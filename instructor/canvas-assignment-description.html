Problem Set 2: Escape from Olin Hall with a missing CornellID

Release: Saturday, September 19, 2026
Initial submission deadline: Saturday, October 3, 2026, at 11:59 PM ET
Maximum score: 4 points

Can you find the shortest route out of a fictional laboratory maze? First, use a queue to search ordinary corridors. Then introduce a locked door and a missing CornellID. The locked door requires your CornellID for access, so your search must distinguish arriving at the same location with and without the card.

On the release page, scroll to Assets and select Source code (zip). Extract the archive completely before beginning. The assignment uses Julia 1.12.7 and standard libraries only.

Complete four functions in src/Compute.jl and the three prompts in responses.md. The map reader, queue, and renderer are supplied. The starter is intentionally incomplete, so the tests initially fail.

Check and submit

In VS Code, open the extracted assignment folder containing Project.toml, README.md, and check_submission.jl. Open a terminal in that folder and run:

julia --startup-file=no check_submission.jl

The check_submission.jl script runs testme_part_1.jl and testme_part_2.jl, with 24 tests per script and 48 tests total, and creates MANIFEST.txt. The Part 1 script tests neighboring cells and shortest routes. The Part 2 script tests CornellID pickup, door access, and shortest routes while tracking whether you have the card.

The script warns if discussion answers are missing or still contain TODO placeholders. After all 48 tests pass, it prints your escape routes through both larger mazes and saves drawings in the outputs folder.

The check_submission.jl script does not upload anything to Canvas. Written explanations and documentation are reviewed separately.

  1. Zip the entire problem-set folder, including your source code, responses.md, data, and generated MANIFEST.txt.
  2. Name the archive CHEME-4800-5800-PS2-<your netid>.zip, replacing the complete placeholder with your NetID. For example: CHEME-4800-5800-PS2-abc123.zip.
  3. Upload the ZIP to this assignment before the deadline.
