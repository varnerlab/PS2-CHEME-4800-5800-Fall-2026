Problem Set 2: Escape from Olin Hall with a missing CornellID

Release: Saturday, September 19, 2026
Initial submission deadline: Saturday, October 3, 2026, at 11:59 PM ET
Maximum score: 4 points

Can you find the shortest route out of a fictional laboratory maze? First, use a queue to search ordinary corridors. Then introduce a locked door and a missing CornellID. The locked door requires your CornellID for access, so your search must distinguish arriving at the same location with and without the card.

Download and instructions

On the release page, scroll to Assets and select Source code (zip). Extract the archive completely before beginning. This problem set is supported with Julia 1.12.7 and uses standard libraries only.

Complete four functions in src/Compute.jl and the three prompts in responses.md. The map reader, queue, and renderer are supplied. The starter code is intentionally incomplete, so the tests will fail initially. Do not modify the supplied tests, data, or submission checker to make an incomplete solution appear to pass.

Check your work

In VS Code, open the extracted assignment folder containing Project.toml, README.md, and check_submission.jl. Open a terminal in that folder and run: 

julia --startup-file=no check_submission.jl

The checker runs testme_part_1.jl and testme_part_2.jl, with 24 tests per script and 48 tests total, and creates MANIFEST.txt. The Part 1 script tests neighboring cells and shortest routes. The Part 2 script tests CornellID pickup, door access, and shortest routes while tracking whether you have the card.

The checker warns if discussion answers are missing or still contain TODO placeholders. After all 48 tests pass, it prints your escape routes through both larger mazes and saves drawings in the outputs folder.

The checker does not upload anything to Canvas. Written explanations and documentation are reviewed separately.

Submit to Canvas

  1. Zip the entire problem-set folder after running the checker, including your source code, responses.md, data, and generated MANIFEST.txt.
  2. Rename the archive to CHEME-4800-5800-PS2-<your netid>.zip.
  3. Replace the complete <your netid> placeholder, including the angle brackets, with your actual NetID. For example: CHEME-4800-5800-PS2-abc123.zip.
  4. Upload the ZIP file to this Canvas assignment before the initial deadline.

If you cannot fix every failing test, submit your current work for partial credit. You must submit something by the initial deadline to participate in the infinite-revision policy. If you make no initial submission, the assignment score is 0 and later revisions will not be accepted for credit.

Revisions

After the initial deadline, eligible students may revise and resubmit PS2 through the end of the semester. Return to this same Canvas assignment, select New Attempt, and upload the revised ZIP file.

Canvas may label these revisions “late.” That is expected and does not create a penalty under the infinite-revision policy. Each revision will be graded, and the highest score earned will be retained.
