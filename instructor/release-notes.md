# CHEME 4800/5800 Problem Set 2

**Escape from Olin Hall with a missing CornellID**

Download **Source code (zip)** under **Assets** and extract the archive.
In VS Code, open the folder containing `Project.toml`, `README.md`, and
`check_submission.jl`. Begin with `README.md`.

Complete the four functions in `src/Compute.jl` and the three questions in
`responses.md`. Run `julia --startup-file=no check_submission.jl` to check
your work. The starter functions are unfinished, so the tests initially fail.
After all 48 tests pass, the checker displays your escape routes and saves
drawings in the `outputs` folder.

The release includes the starter code, four mazes, queue, drawing functions,
test scripts, submission checker, and grading rubric. The reference solution
is not included. Use Julia **1.12.7**; no external packages are required.
